# TypeScript JSDoc Style (Skill)

Agent skill for **TypeScript JSDoc and comment** conventions when writing or
reviewing documentation in TypeScript source.

## When to use

- Writing, reviewing, or refactoring comments, JSDoc, `@param`/`@returns`, or
  class/method documentation in TypeScript.
