# SOLID Design Principles — TypeScript (Skill)

Agent skill for applying **SOLID** (SRP, OCP, LSP, ISP, DIP) when designing and
reviewing **TypeScript** modules, classes, interfaces, and services.

## When to use

- Design or review TypeScript architecture for maintainability.
- Keywords: SOLID, SRP, OCP, LSP, ISP, DIP, dependency injection, interface
  segregation, code smells, strategy pattern.
